# RC-Z8BASIC - a Z8 BASIC/DEBUG homebrew computer

I stole Hackaday.io user: [Just4Fun's](https://hackaday.io/Just4Fun) [RC-Z8BASIC - a Z8 BASIC/DEBUG homebrew computer](https://hackaday.io/project/168014-rc-z8basic-a-z8-basicdebug-homebrew-computer). Jus4Fun created this on 10/14/2019. These are the files. I have a couple of Z8 BASIC processors (along with a 68701 and a few 8052BASIC chips) so I wanted something to show them off.

# Zilog Z8 BASIC

Zilog made the Z8 starting in 1979 and one of the derivative chips they made was the Z8 BASIC chip (Z8671 or Z0867108). The Z8 is a microcontroller similar to the Intel 8051 familt of microcontrollers.
